# NowTuneUp 1.7.1

NowTuneUp 1.7.1 adds configurable numeric ranges for dashboard widgets while preserving the Time Slip, OBD-II, Bluetooth, USB, diagnostics and saved-profile behavior from version 1.7.0.

## Dashboard widget ranges

- Set an independent minimum and maximum scale for each widget.
- Speed widgets default to `0–200 km/h`.
- Engine RPM widgets default to `0–7,000 rpm`.
- Analog gauges use the configured range for labels and needle position.
- Digital-ring widgets use it for scale labels and illuminated segment progress.
- Progress widgets normalize their bar using the configured range.
- Clearing both values restores automatic scaling from OBD metadata.
- Invalid, incomplete, equal or reversed ranges cannot be saved or imported.
- Custom ranges are stored per dashboard profile and preserved through JSON export/import.

## Compatibility

Existing dashboard profiles without custom range fields continue to use automatic OBD-derived ranges. No database migration is required.
