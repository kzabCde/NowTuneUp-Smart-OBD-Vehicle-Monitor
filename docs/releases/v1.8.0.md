# NowTuneUp 1.8.0 — Accurate Time Slip

NowTuneUp 1.8.0 upgrades performance testing from OBD-only timing to a timestamped sensor-fusion workflow while preserving Bluetooth Classic, USB, customizable dashboards, Turbo Pressure, HUD, diagnostics and local-first storage.

## Accurate Time Slip

- Dedicated speed-priority OBD sampling during an armed or running test.
- Monotonic timestamps captured at the OBD command/response boundary.
- Speed PID readiness gate based on support, freshness, stable samples and sample rate.
- Optional OBD + GNSS + accelerometer fusion without storing GPS coordinates.
- GNSS accuracy, satellites used, transport latency and road slope diagnostics.
- Reaction time separated from elapsed time.
- Optional one-foot rollout for drag-style comparisons.
- Raw telemetry recording, replay and Speed vs Time graphs.
- Comparison between two saved runs and best-run filtering by vehicle profile.
- Separate speed and distance confidence grades with estimated timing error.
- Text, CSV and generated image sharing.

## Reliability and diagnostics

- Foreground monitoring service owns the singleton OBD polling session while active.
- Hardware diagnostic report includes ELM identity, ECU state, supported PIDs, speed sample rate, latency and diagnostic logs.
- Existing automatic reconnect and ELM327 soft stream recovery remain enabled.

## Safety and accuracy

Use Time Slip only on a closed course or authorized private property. GNSS and OBD timing remain consumer-device measurements and should be verified against certified track timing equipment when official results are required.
