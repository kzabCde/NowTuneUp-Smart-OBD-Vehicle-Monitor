# NowTuneUp 1.19.1 — Professional Automotive Dashboard

Android build code: **30**. Requires Android 8.0 or later.

- Five primary destinations: Home, Performance, History, Garage and Settings,
  with adaptive navigation, light/dark themes and reduced-motion support.
- Two primary gauge presentations: DialGauge and DigitalGauge. Older saved
  gauge configurations retain IDs, geometry, sources, ranges and compatibility data.
- Dashboard create, rename, duplicate, reorder, preferred landing, reset and
  confirmed deletion. Deleting the final dashboard leaves an empty Home with a
  Create Dashboard action, including after restart.
- Widget add/remove, reorder, resize, style/source/range editing and undo/redo.
  Daily, Engine and Performance templates are explicit editable copies.
- Dedicated performance history, clear legacy/unavailable states and locally
  generated PNG reports shared through Android Sharesheet.
- Garage groups vehicle profiles, adapter connection, read-only diagnostics,
  live telemetry and observed connection health. Unknown health is not shown as 100%.
- Compact gauge labels, fullscreen status placement and system-bar contrast
  protect readability across supported layouts.

Existing OBD transports, session handling, PID parsing, measurement calculations,
analysis and stored run formats are retained. Dashboard deletion does not delete
vehicles, trips, telemetry or performance history. No account or backend is required.
Distance and acceleration remain estimates from OBD speed, not GPS-grade timing.

## Verification

132 JVM tests passed in each of debug and release configurations. Debug and
release lint passed with zero errors and 42 warnings each. All 21 device test
cases passed across a full run and one unchanged focused rerun after a Compose
idle timeout on the software emulator. The final dashboard's deletion was verified
through the real UI, database inspection and process restart.

Physical USB/Bluetooth compatibility, extended monitoring, startup/frame-rate
profiling and OEM lifecycle/cutout behavior still require real-device validation.
