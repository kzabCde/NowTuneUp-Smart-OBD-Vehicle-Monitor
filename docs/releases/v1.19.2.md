# NowTuneUp 1.19.2 — Dashboard & Gauge Hotfix

Android version **1.19.2**, build code **31**, Android 8.0 or newer.

## What's improved

- Dashboard profiles now have a visible **ลบ** (Delete) action in the workspace list, rather than requiring a nested overflow menu. Deletion still asks for confirmation.
- The app keeps the deletion dialog open if the storage operation fails and explains the failure rather than closing as though it succeeded.
- Dashboard management remains accessible during Driving Mode so the user can see why controls are locked. Changes and deletion still require Driving Mode to be turned off safely while parked.
- The analog dial reduces crowded tick marks, needle weight and scale chrome. Digital gauge typography is quieter, with aligned labels, values and units.
- Existing two gauge types, OBD read-only monitoring, Time Slip measurements, workspace persistence, vehicle/trip/run history and local-first behavior are preserved.

## Important limitations

- A profile deleted on an older version may require review on a real device. Users should check Home → Manage dashboards and confirm deletion before assuming success.
- This UI release does **not** change OBD timing accuracy, sensor precision, connection compatibility, or performance-test algorithms. Estimates remain estimates; no GPS-grade precision is claimed.

## Release checks

Build from a clean, immutable `v1.19.2` source tag using the repository's **Publish Android release** workflow. Release is only valid if Android tests/lint, production signing, APK metadata verification and SHA-256 checks succeed. Website sync must verify the published APK and propose its own website PR.

Do not overwrite the existing `v1.19.1` tag or signed APK. The app version and code increase together for upgrade compatibility.
