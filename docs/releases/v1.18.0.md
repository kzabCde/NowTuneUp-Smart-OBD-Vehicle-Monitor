# NowTuneUp 1.18.0 — Motorsport Performance Suite

Android version code: **28**. Android 8.0+ remains supported.

- Optional Daily Drive, Performance and Diagnostics HUD templates, independent
  orientation layouts, configurable RPM shift stages and compact digital gauges.
- Clear disconnected/stale/unsupported states, simulation labels, safe unit/source
  editing and last-scan DTC availability.
- Bounded raw telemetry recording with original source timestamps, separate signal
  axes, measured-sample inspection, local history, confirmed deletion and CSV export.
- Exact 0–60 mph target, searchable/grouped/sorted performance history, compatible
  comparisons and split deltas. New runs retain available timestamped RPM/throttle;
  older records remain accessible without invented measurements.
- Source, quality and rollout context in results and local sharing. Existing timing
  calculations, Room profiles, DataStore preferences and transports are retained.

Shift thresholds must be configured by the driver; no manufacturer redline is
assumed. Distance and acceleration are estimates derived from OBD speed and are
not certified GPS timing measurements. Core monitoring remains local-first.

## Validation and limitations

The development suite passed 116 JVM tests, lint, debug build and instrumentation
APK assembly using USB serial built from its official v3.9.0 source. Normal CI
against the declared JitPack dependency is required before publication. Device
UI tests did not complete because the unaccelerated emulator was unstable.
Physical USB/Bluetooth compatibility and extended monitoring remain unverified;
see `docs/development/motorsport-suite.md` for the complete verification record.

The production APK must use the existing release signing identity so upgrades
preserve installed application data. Never publish an unsigned or debug APK as
this release. Website size and SHA-256 must come from the verified signed APK.
