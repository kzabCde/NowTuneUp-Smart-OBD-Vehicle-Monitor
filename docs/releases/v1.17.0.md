# NowTuneUp 1.17.0 — Custom HUD Studio

## Custom HUD replaces the legacy HUD

NowTuneUp 1.17.0 removes the separate fixed Speed / RPM / Turbo HUD and replaces it with one user-owned dashboard system. The selected HUD profile is the source of truth for normal dashboard, fullscreen focus and mirrored projection use.

## Freeform canvas

- 12 × 24 logical canvas instead of pixel coordinates
- independent Portrait and Landscape layouts
- drag widgets to move them
- resize widgets from the corner handle
- snap-to-grid geometry that survives different screen resolutions
- z-order controls for overlapping widgets
- lock individual widgets to protect their position
- per-widget opacity

## Widget Library

A data source can be visualized more than once without requesting the PID more than once from the OBD session.

Available presentations include:

- Digital value
- Analog gauge
- Mini gauge
- Digital ring
- Progress meter
- Realtime line chart
- DTC status

For example, RPM may appear simultaneously as an analog gauge, a digital value and a realtime graph.

## Profiles

- create multiple independent HUD profiles
- swipe between saved profiles
- separate Portrait and Landscape layouts
- duplicate individual widgets
- import/export profiles as JSON
- Undo / Redo while editing
- old saved dashboard profiles migrate into the freeform canvas instead of being discarded

## Widget configuration

Each widget can define:

- data source
- visualization type
- unit and decimals
- value text size
- custom scale
- warning and critical thresholds
- gauge style
- canvas position and size
- z-order
- lock state
- opacity

## Safety

HUD editing stays unavailable while Driving Mode is active. Live OBD data remains read-only and the visual layout does not alter ECU values or Time Slip measurement timestamps.

## Compatibility

Android 8.0+ · Bluetooth Classic + supported USB serial adapters.
