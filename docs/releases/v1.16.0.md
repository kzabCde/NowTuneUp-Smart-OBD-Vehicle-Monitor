# NowTuneUp 1.16.0 — Performance Insights

Android version `1.16.0`, version code `26`.

![Pulse N icon](../assets/pulse-icon-preview.png)

## What changes

- Interactive speed, estimated longitudinal acceleration (g), and estimated distance charts for newly recorded Time Slip runs. A slider reads individual samples without relying on color alone.
- Compare against the previous completed run with the same vehicle, mode, distance/speed target and rollout setting. Solid and dashed lines distinguish the runs; the elapsed-time delta remains visible.
- Open full results from history, including split times, quality information and charts. All saved runs (up to the existing 100-record retention limit) are reachable. Delete now has a confirmation step.
- A quieter shared interface: plain section headers, subtle panel borders, smaller corner radii, separate Test/History controls, and expandable signal diagnostics. Existing themes and reduced-motion preferences remain supported.
- New Pulse N identity across adaptive, round and Android 13 monochrome icons, the splash/in-app mark, and the shared website logo.
- Shared result text now uses the actual app version instead of a stale hard-coded version.

## Data and compatibility

Timing start, launch, launch speed and interpolated completion timestamps are stored alongside each new result. The graph uses monotonic OBD timestamps, clips to the actual run, and excludes pre-launch waiting samples. No wall-clock reconstruction is used.

The acceleration graph is calculated from OBD speed differences, not an IMU G-force measurement. Distance is estimated by integrating OBD speed. Intervals longer than 1.5 seconds break the graph; acceleration is omitted across the gap and cumulative distance becomes unavailable. A finish inside such a gap is not invented. Truncated recordings are explicitly identified.

Existing saved results and preferences are retained. Results recorded before 1.16 lack reliable run boundaries and show their original split values with an explanation that a new run is needed for charts. No sample/demo curves are shown as real results.

This release does not add Dragy-device pairing, GPS precision claims, leaderboards, or a new measurement source. The feature reference is [Dragy Connect](https://apps.apple.com/us/app/dragy-connect/id1260905448) and [Dragy's performance-measurement overview](https://dragymotorsports.com/); implementation and visual identity are native to NowTuneUp.

## Verification

- Unit coverage: start/finish interpolation, rollout time origin, distance and acceleration, data gaps, invalid/duplicate samples, legacy JSON and valid comparison groups.
- Compose coverage: chart switching, comparison, 320 dp width, increased text size, light/dark themes and the legacy empty state. The UI workflow exports performance-screen screenshots.
- Release gates: Android unit tests, lint, debug APK and instrumentation APK, followed by emulator UI tests in the pull request workflow.
- A real ELM327/vehicle test remains necessary to validate sampling quality and hardware behavior. Publishing a signed production APK follows the existing release workflow after review.
