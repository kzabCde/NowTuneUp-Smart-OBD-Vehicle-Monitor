# NowTuneUp 1.15.0 — Graphite UI & Motion

Android version `1.15.0`, version code `25`. This is the next Android release candidate after `1.14.0` / `24`.

## What changes

- A redesigned N/telemetry launcher mark, matching Compose splash and in-app identity, adaptive round/squircle support, Android 13 monochrome icons, and a transparent notification mark.
- A complete Material 3 palette for surfaces, outlines, text, actions, errors and containers. New installs use Graphite/electric green. Settings offers Graphite, Daylight and cyan; previously saved custom themes remain intact.
- Shared outlined cards, screen introductions, clearer typography and explicit empty-state actions across vehicle setup, dashboard, connection, live data, diagnostics, Time Slip, settings and the dashboard editor.
- A compact app bar with a truncated vehicle name, connection status and two accessible actions. Phone navigation uses selected labels and animated icons; the rail can scroll on short landscape displays.
- Directional page transitions, press feedback for selectable cards, a shorter branded launch sequence, and a common reduced-motion setting for card resizing. Motion stays in Compose and adds no OBD polling or telemetry timers.
- Thai vehicle setup and connection copy, full-row settings switches, live-data value/unit hierarchy, and readable HUD/Min–Max overlays under the light theme.
- The Android Back button closes the editor, returns from vehicle management, or returns to the dashboard from a tab. The selected tab and splash completion survive configuration changes.
- App version and APK filenames are derived from Gradle metadata rather than hard-coded UI strings.

## Data and compatibility

No database schema or transport/command/session engine changes. Vehicle profiles and dashboards still start empty and are created by the user. No sample vehicles or dashboard layouts are inserted. Existing profiles, custom gauge colors, responsive layouts, histories and imports/exports retain their storage format.

Bluetooth Classic, USB, DTC actions, connection recovery, Time Slip calculations, Focus Mode, Touch Lock and HUD remain available. App theme selection does not overwrite individual gauge themes.

The published website and its canonical signed `1.14.0` APK remain at their existing release until a separate signed release is published. This change does not create a production tag or replace the download APK.

## Review

Android Studio debug previews are in `app/src/debug/java/com/nowtuneup/app/DesignPreviews.kt` (Graphite, Daylight and 150% font scale). Instrumentation checks cover the explicit first-run action, light-theme header and clickable card semantics with reduced motion. Unit checks cover theme contrast and the existing dashboard/OBD/Time Slip regression suite.

Validation results are recorded in the pull request. Before publishing a signed release, check the real Bluetooth/USB adapter, full-screen HUD and launcher themed-icon behavior on a physical device.
