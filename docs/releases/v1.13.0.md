# NowTuneUp 1.13.0

NowTuneUp 1.13.0 is a consolidated release train covering the planned 1.10, 1.11, 1.12 and 1.13 capability milestones. Intermediate versions were developed as milestones and are not published as separate production APKs.

## 1.10 — Adaptive Connection v2

- Adds a local Adapter Profile keyed by vehicle/adapter identity when available.
- Records bounded adapter-health history: grade, recommended polling mode, latency, success rate, command rate and recovery activity.
- Adds a 0–100 stability score and keeps FAST / BALANCED / STABLE recommendations visible in the connection flow.
- Keeps existing automatic pacing and soft recovery behavior from 1.9.0.

## 1.11 — Live Data v2

- Adds an opt-in local Live Session recorder.
- Records supported live values without adding cloud dependencies.
- Produces per-PID Min / Max / Average / latest summaries and frame counts.
- Keeps a bounded local session history and stops recording safely when leaving Live Data.

## 1.12 — Diagnostics v2

- Adds a bounded local diagnostic history with VIN, MIL state and Stored/Pending/Permanent DTC counts.
- Keeps Readiness and Freeze-frame trigger information in the existing read-only workflow.
- Adds optional OBD Mode 06 monitor probing with graceful fallback when the ECU or adapter does not expose Mode 06 data.
- Mode 04 remains an explicit destructive action behind confirmation.

## 1.13 — Time Slip v2

- Keeps Time Slip OBD-only and prioritizes PID 010D during a run.
- Adds automatic launch validation and rejects implausible launch speed jumps.
- Uses monotonic timestamps with interpolated speed/distance crossings.
- Adds a 0–100 run quality score based on OBD sample rate, transport latency, dropped samples and whether distance is estimated from speed integration.
- Stores average transport latency, invalid-sample ratio, validity notes and estimated timing error with each result.
- Existing local Time Slip history remains backward-compatible through default values on the new fields.

## Release and compatibility

- Android version: 1.13.0
- Version code: 23
- Minimum Android: Android 8.0 (API 26)
- Connection paths: Bluetooth Classic SPP/RFCOMM and supported USB serial adapters
- Vehicle/adapter PID support still varies by ECU and ELM327 implementation.
- No cloud account is required for the core OBD session, histories or session recording.

## Safety

NowTuneUp is a diagnostic and telemetry aid, not a substitute for professional mechanical inspection. Do not interact with diagnostic controls while driving. Use Time Slip only on a closed course or private property where performance testing is permitted.
