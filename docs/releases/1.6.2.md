# NowTuneUp 1.6.2

Version code: 13

## User-facing changes

- Removed the Trips destination, Trips screen, and background Trip recording runtime.
- Removed bundled default dashboard layouts. The dashboard now starts empty until the user creates and saves a profile.
- Added user-created dashboard profiles with independent portrait and landscape layouts.
- Preserved profiles that users saved in earlier versions and converted them to normal editable user profiles.
- Replaced technical widget configuration wording with everyday Thai labels.
- Replaced manual ARGB/hex color entry with visual, named color choices.
- Kept premium gauges, digital rings, thresholds, profile import/export, Bluetooth Classic SPP, USB, Turbo, HUD, and DTC functions.

## Release validation

- Android unit tests passed.
- Android lint passed.
- Debug APK assembly passed.
- Signed release APK assembly passed with repository Actions secrets.
- APK verification passed before the signed file was bundled with the website.
- Production APK SHA-256: `302863da251840028b03b6c7368b915641e569e3d0e94e4b14f4053571c887af`.

The legacy Trip database tables remain in the schema only to avoid breaking upgrades from existing installations. They are not exposed by the 1.6.2 UI and are no longer used by the runtime recorder.
