# NowTuneUp 1.8.1 — Stability and UX Hotfix

NowTuneUp 1.8.1 prioritizes reliable live data and simple daily use over adding more controls. This release reduces the workload placed on low-cost ELM327 adapters and removes duplicated or confusing interface options.

## Realtime OBD stability

- Use conservative command pacing for Bluetooth Classic and USB adapters.
- Increase live PID timeouts to tolerate slower ELM327 clones.
- Treat transient timeout, buffer and ECU delays as recoverable conditions.
- Run soft stream recovery without immediately closing a healthy Bluetooth socket.
- Catch unexpected polling errors so one malformed response does not terminate the live session.
- Keep true socket closure and broken-pipe errors as automatic reconnect triggers.

## Stable Turbo Pressure

- Recalculate Turbo Pressure only when MAP or BARO receives a new sample.
- Stop unrelated PID updates from repeatedly advancing the Turbo filter.
- Use a five-sample MAP median window and a slow BARO baseline.
- Show stale Turbo data as unavailable instead of snapping to zero.
- Add regression tests for spike rejection, stale data and repeated reads.

## Dashboard data clarity

- Remove Peak from the interface because it used the same calculation as session Maximum.
- Keep one clear Min/Max session summary per widget.
- Use Thai freshness labels for delayed, stale and reconnecting data.

## Simple Time Slip

- Make OBD-only speed measurement the default production flow.
- Start speed-priority sampling while the Time Slip screen is open.
- Support four clear presets: 0–60 km/h, 0–100 km/h, 60–100 km/h and 1/4 mile.
- Remove sensor setup, comparison, replay, graphs and advanced rollout controls from the main flow.
- Use a short setup → ready → running → result interaction model.
- Keep results local with simple share and delete actions.

## UX simplification

- Live Data reads automatically and shows only supported values.
- Remove manual pause/resume controls that could leave polling in an unexpected state.
- Reduce Settings to four sections: Connection, Data Reading, Dashboard and Diagnostics.
- Hide advanced reconnect timing, alert tuning, HUD internals and device-layout overrides from the default settings experience.
- Label the Balanced reading mode as recommended and the Low mode as most stable.

## Release

- Android versionName `1.8.1`.
- Android versionCode `18`.
- Signed APK filename `NowTuneUp-v1.8.1-release.apk`.
- The signed APK must pass unit tests, Android lint, archive validation and `apksigner` verification before being bundled into the website.

Physical testing with the target vehicle and ELM327 adapter remains required to verify real commands per second, Turbo behavior and disconnect frequency under road vibration and electrical noise.
