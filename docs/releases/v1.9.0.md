# NowTuneUp 1.9.0 — Adaptive Stability & Vehicle Intelligence

NowTuneUp 1.9.0 combines the planned 1.8.2 stability foundation with the 1.9.0 Vehicle Intelligence milestone. The release keeps the normal UX simple while moving adapter tuning, polling decisions and vehicle identification into automatic background logic.

## 1.8.2 stability foundation

### Adaptive OBD polling
- Track rolling ELM327 command latency, success rate, commands per second and soft recovery count.
- Classify the live link as Good, Fair or Poor.
- Recommend Fast, Balanced or Stable polling automatically.
- Enforce a conservative pacing floor when the adapter becomes slow or unreliable, even if the user requested Fast mode.

### Demand-based PID scheduling
- Dashboard polling requests only the PIDs used by the selected dashboard profile.
- Turbo widgets automatically expand into MAP + BARO dependencies.
- Live Data requests the full supported PID set only while that screen is visible.
- Time Slip continues to use its dedicated speed-priority scheduler.
- Diagnostics pause realtime polling while running multi-command scans.

### Turbo Pressure v2
- Keep the five-sample MAP median and slow BARO baseline.
- Add key-on/engine-off MAP baseline calibration when RPM is near zero.
- Publish Turbo only when the MAP/BARO pair quality is Good; otherwise show unavailable instead of a misleading value.
- Surface Turbo quality in Live Data and diagnostics.

### Session diagnostics
- Persist the previous OBD session report locally.
- Include adapter health, latency, success rate, command rate, recovery count, requested PIDs, Turbo quality and VIN.
- Add an ELM327 compatibility self-test with voltage, RPM, speed, MAP and BARO checks when supported.

## 1.9.0 Vehicle Intelligence

### VIN-based vehicle profile
- Read Mode 09 PID 02 VIN when supported.
- Persist VIN, ELM327 identity, supported Mode 01 PIDs, recommended polling mode and last-seen time.
- Reuse the detected vehicle identity across the diagnostics/settings UX.

### Read-only vehicle health scan
- Mode 03 Stored DTC.
- Mode 07 Pending DTC.
- Mode 0A Permanent DTC.
- Mode 01 PID 01 MIL state and DTC count/readiness bytes.
- Mode 02 freeze-frame trigger DTC where supported.
- Mode 09 PID 02 VIN.

Mode 04 Clear DTC remains a secondary, explicitly confirmed action.

### Simplified UX
- Live Data shows OBD health and automatically requests all supported values only while open.
- Settings remains four main areas and explains that advanced adapter pacing is automatic.
- Diagnostics becomes the single place for vehicle scan, VIN, readiness, extended DTC classes, freeze-frame trigger and adapter self-test.
- Removed unused Time Slip compare/replay/CSV/best-run repository functions left from the older 1.8.0 UI.

## Release
- Android versionName: `1.9.0`.
- Android versionCode: `19`.
- Release APK: `NowTuneUp-v1.9.0-release.apk`.
- The release pipeline must pass unit tests, Android lint, debug assembly, signed release assembly, ZIP validation and `apksigner` verification before website metadata is updated.

## Physical validation boundary
CI cannot reproduce every ELM327 clone, ECU response pattern, vehicle voltage condition or Bluetooth radio environment. Final validation still requires the target vehicle and adapter, especially for live command rate, disconnect frequency, Turbo behavior, Mode 09 VIN support and Time Slip sample rate.
