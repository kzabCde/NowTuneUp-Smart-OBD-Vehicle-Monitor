# NowTuneUp 1.0.0

The first stable NowTuneUp release brings local, read-only OBD-II monitoring to Android 8.0 and newer devices.

## Highlights

- Live RPM, speed, coolant temperature, voltage, engine load, and throttle telemetry.
- Read-only stored diagnostic trouble code scanning.
- USB OTG support for ELM327-compatible adapters.
- Local trip history, settings, and CSV export with no account or cloud backend.
- Portrait and landscape dashboard layouts, plus a mock OBD mode in debug builds.

## Install

Download `NowTuneUp-v1.0.0-release.apk` and verify it with the accompanying SHA-256 file before installing. Android may ask you to allow installation from your browser or file manager.

NowTuneUp does not clear codes, write to the ECU, flash, or code vehicle modules. Park safely before interacting with the application.
