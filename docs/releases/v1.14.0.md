# NowTuneUp 1.14.0

NowTuneUp 1.14.0 introduces user-owned vehicle profiles and a consistent premium automotive motion system across the Android app.

## Vehicle profiles

- Fresh installations start with zero vehicle profiles and zero fake/demo vehicle data.
- Removed automatic/default/demo/sample vehicle persistence.
- VIN detection remains available for diagnostics but can no longer create saved vehicle profiles.
- Adds explicit Create, Edit, Delete, Duplicate and Select Active Vehicle flows.
- Vehicle profiles support nickname, brand, model, year, engine, fuel type, transmission, optional VIN and notes.
- Legacy `profiles_v1` is intentionally not migrated because those records were generated automatically from detected VINs.
- Vehicle-specific screens require an explicitly created active vehicle.

## Premium automotive motion

- Adds a new N + tachometer adaptive launcher icon with graphite, white and electric-green visual language.
- Adds an animated splash screen with logo entrance and RPM sweep without adding artificial loading delay.
- Adds reduce-motion-aware page, connection-state and interaction transitions.
- Adds animated Disconnected → Connecting → Connected/Error presentation while keeping Bluetooth/OBD transport logic independent.
- Keeps dashboard gauge interpolation presentation-only; actual OBD telemetry values are never modified by animation.

## Time Slip

- Removes the hardcoded `default` vehicle profile identifier and binds new Time Slip records to the active user-created vehicle.
- Adds 0–60 km/h, 0–100 km/h, 1/4 mile, 1/2 mile and 1 mile presets.
- Adds a 3 → 2 → 1 → GO presentation countdown, smooth live speed display, milestone animation and personal-best indication.
- Timing continues to use actual OBD telemetry timestamps and interpolated crossings; animation timing does not affect recorded results.

## Performance and accessibility

- Uses Compose transform/opacity-oriented motion and bounded animations suitable for mid-range Android devices.
- Respects the app Reduce Motion preference.
- Avoids continuous decorative animations that could interfere with OBD processing.
- Preserves the existing OBD2 session, diagnostics, dashboard and local-first architecture.

## Release and compatibility

- Android version: 1.14.0
- Version code: 24
- Minimum Android: Android 8.0 (API 26)
- Connection paths: Bluetooth Classic SPP/RFCOMM and supported USB serial adapters
- Core OBD functionality remains local-first and does not require an account or cloud backend.

## Safety

NowTuneUp is a diagnostic and telemetry aid, not a substitute for professional mechanical inspection. Do not interact with diagnostic controls while driving. Use Time Slip only on a closed course or private property where performance testing is permitted.
